FaB Paxos example execution: recovery (leader change)
=====================================================

Scenario: a correct leader, all acceptors correct, a single value v0, two terms
(MaxPN = 1). Shows the recovery path: proposers suspect the leader, a new leader
is elected at the next proposal number, it queries the acceptors, gathers a
progress certificate from their replies, proposes, and a learner decides at
proposal number 1.

How produced: TLC breadth-first search, the shortest run that violates the
read-only observer NeverLearnedAtPN1 defined in MCFaBPaxosTrace.tla. Proposal
number 1 is reachable only through a LeaderChange, so the shortest run that
learns at pn 1 must take the whole recovery path. The protocol in FaBPaxos.tla
is unmodified. The state blocks below are TLC output, verbatim. The full
untrimmed log is in recovery.raw.txt.

Command (run from spec/):
  java -jar ~/tools/tla2tools.jar -fp 1 -config traces/recovery.cfg MCFaBPaxosTrace.tla

Reading: three SuspectLeader steps reach the suspicion threshold
ceil((p + f + 1) / 2) = 3, then LeaderChange moves to pn 1, Query and five Reply
steps build the progress certificate, LeaderPropose proposes the certified
value, five Accept steps form the fast quorum, and learner l1 decides in
State 18.
