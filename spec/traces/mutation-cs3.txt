FaB Paxos counterexample: weakened fast-learn quorum (mutation test)
=======================================================================

WARNING: this is an execution of a DELIBERATELY BROKEN variant, not the real
protocol. We temporarily weakened the fast-learn quorum in FaBPaxos.tla from
ceil((a + 3f + 1) / 2) = 5 to ceil((a + f + 1) / 2) = 4, ran the safety config,
captured this counterexample, then reverted the change.

Purpose: this is our mutation test. A clean verification means little if the
invariants cannot fail. With the weaker quorum, a learner can decide a
pair that fewer than the chosen threshold of correct acceptors accepted, so it
learns a value that is not chosen, and CS3 fails. TLC finds the violation, which
shows the model does detect real safety failures. The real spec uses quorum 5 and
has no such violation.

How produced: safety config (MCFaBPaxos.cfg) with the weakened quorum.
Full untrimmed log: mutation-cs3.raw.txt.
