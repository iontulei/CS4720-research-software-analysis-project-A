FaB Paxos example execution: common case
========================================

Scenario: a correct leader, all acceptors correct, a single value v0, one term
(MaxPN = 1). Shows the two-step common case: the leader proposes, a fast quorum
of acceptors accepts, and a learner decides.

How produced: TLC breadth-first search, the shortest run that violates the
read-only observer NeverLearned defined in MCFaBPaxosTrace.tla. The protocol in
FaBPaxos.tla is unmodified; the observer only reads state, so this is a faithful
run of the real protocol. The state blocks below are TLC output, verbatim. The
full untrimmed log is in common-case.raw.txt.

Command (run from spec/):
  java -jar ~/tools/tla2tools.jar -fp 1 -config traces/common-case.cfg MCFaBPaxosTrace.tla

Reading: State 1 is the initial state. Each later state names the action that
fired. ACCEPTED messages build up in msgs; once five match (the fast-learn
quorum ceil((a + 3f + 1) / 2) = 5 at f = 1), learner l1 decides v0 in State 8.
